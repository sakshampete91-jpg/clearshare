# Threat Model — CLEARSHARE

## Scope

This threat model evaluates CLEARSHARE as a **100% client-side static React + TypeScript application** with zero backend server, zero user accounts, and zero Firebase/Google Cloud service integrations.

## Threat Matrix

| ID | Threat / Attack Scenario | Severity | Target Layer | Implemented Mitigation | Verification / Evidence | Residual Risk |
|---|---|---|---|---|---|---|
| **TM-01** | **Stored/Reflected DOM XSS via Malicious Document (`<script>`, `<img onerror>`)** | HIGH | Document Viewer & Tables | Content rendered strictly via React JSX text nodes; zero `dangerouslySetInnerHTML`, `innerHTML`, `eval()`, `Function()`. CSP disables inline scripts (`script-src 'self'`). | [HighlightedViewer.tsx](../frontend/src/components/analysis/HighlightedViewer.tsx), `ci.yml`, `appFlow.test.tsx` | Compromised browser extension altering DOM directly |
| **TM-02** | **Spreadsheet CSV Formula Injection (`=CMD`, `+`, `-`, `@`)** | HIGH | CSV Export Engine | `neutralizeCsvFormulaCell` prefixes leading `=`, `+`, `-`, `@`, `\t`, `\r` with `'` across CSV cells, CSV headers, and plain-text-to-CSV exports. | [inputGuards.ts](../frontend/src/security/inputGuards.ts), [csvProcessor.ts](../frontend/src/engines/export/csvProcessor.ts), `csvProcessor.test.ts` | Legacy spreadsheet apps ignoring apostrophe escaping on non-standard triggers |
| **TM-03** | **Catastrophic Backtracking (ReDoS) via Custom Regex** | HIGH | Custom Pattern Engine | `validateCustomRegexPattern` caps patterns at `120` chars, blocks nested quantifiers (`(a+)+`), and rejects empty-matching regexes; large inputs clamped at `500k` chars. | [inputGuards.ts](../frontend/src/security/inputGuards.ts#L41-L78), `verificationAndSecurity.test.ts` | Complex non-nested regex patterns on near-500k char text could still increase CPU time transiently |
| **TM-04** | **Browser Resource Exhaustion / Malformed PDF/DOCX Payload** | MEDIUM | Client File Extractors | Extension/MIME validation, magic bytes (`%PDF-`, `PK`), size limits (`2 MB` text / `5 MB` binary), `50`-page PDF cap, `useWorkerFetch: false`, `useSystemFonts: false`. | [documentExtractor.ts](../frontend/src/engines/export/documentExtractor.ts), `fileExtractors.test.ts` | Deeply crafted parser edge cases inside upstream `pdfjs-dist` or `mammoth` binaries (monitored via `npm audit` & Dependabot) |
| **TM-05** | **Cross-Origin / Malformed `postMessage` to Web Worker** | MEDIUM | Dedicated Worker Boundary | Both `documentProcessing.worker.ts` and `AppContext.tsx` verify `event.origin` (`''` or exact `window/self.location.origin`) and payload structure before execution. | [documentProcessing.worker.ts](../frontend/src/workers/documentProcessing.worker.ts), [AppContext.tsx](../frontend/src/app/AppContext.tsx) | Same-origin XSS would share origin; prevented by TM-01 CSP + React escaping |
| **TM-06** | **Secret or PII Leakage in Diagnostics, Logs, Reports, Errors, or Filenames** | HIGH | UI, Error Handling & Exports | Secrets masked (`[SECRET ••••xxxx]`); `reportService` excludes text/values/pseudonyms; `buildSafeAppError` redacts emails/tokens and strips newlines; `sanitizeDisplayFilename` strips paths; `ci.yml` blocks `console.log`. | [categoryMeta.ts](../frontend/src/utils/categoryMeta.ts), [reportService.ts](../frontend/src/services/reporting/reportService.ts), `verificationAndSecurity.test.ts` | User viewing screen directly (shoulder surfing) or exporting unmasked indirect clues when residual warnings are present |
| **TM-07** | **Clickjacking, Framing, or Protocol Downgrade in Deployment** | MEDIUM | Static Web Hosting (`nginx.conf`) | `frame-ancestors 'none'`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `COOP: same-origin`, `CORP: same-origin`, `HSTS`, `server_tokens off`. | [nginx.conf](../nginx.conf) | Depends on deploying behind HTTPS/TLS reverse proxy or Nginx container in production |
| **TM-08** | **Accidental Credential Commit or Vulnerable Dependency** | CRITICAL | GitHub Repository & CI/CD | Runtime-assembled synthetic test fixtures; CI secret & storage grep; CodeQL (`security-extended`); Dependabot; PR Dependency Review; `npm audit --audit-level=moderate`. | [.github/workflows/ci.yml](../.github/workflows/ci.yml), [codeql.yml](../.github/workflows/codeql.yml), [dependency-review.yml](../.github/workflows/dependency-review.yml) | Historical commit `cf36e978` retains synthetic test fixture string `AIza...123` (verified synthetic; open Alert `#1` pending manual UI close) |
